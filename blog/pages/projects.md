## 一些在用的项目

> 记录自己一直比较常用的项目，包括开源的、免费的、收费的。

- 会列出本人在使用的主要平台，如果缺少其他平台，不代表没有
- 开源的软件会给出对应的 github 地址；收费的会给出官方发布站

## fd

>一个**开源**的命令行快速查找文件的工具，参考 Linux 上的 `find` 指令。

- Windows、Linux
- [sharkdp/fd](https://github.com/sharkdp/fd)

## Frp

> **开源**的内网穿透，相关技术在过往的文章有所介绍，我个人的服务器 + itx 本地主机 + Frp，组成了我的互联网技术路。

- Windows、Linux
- [fatedier/frp](https://github.com/fatedier/frp.git)

## Typora

> 个人最喜欢、最常用的 Markdown 编写平台，基本所有只要能用 Markdown 展示的文章，我都会优先选择使用 Markdown 语言，以及用来编写它的 Typora。软件是**买断**制的，可供 3 个平台同时使用，价格是 98 RMB。

- Windows、Linux
- [Typora 官方中文站](https://typoraio.cn)

## Notepad3

> 一个用来替代 Windows 平台下原生的 notepad 的**开源**软件，打开轻量级文件类型的时候很好用，例如 `.txt`、`.ini`、`.conf` 等文件类型。

- Windows
- [rizonesoft/Notepad3](https://github.com/rizonesoft/Notepad3.git)

## Microsoft Visual Studio Code

> 最喜欢的可扩展性**开源**文本编辑器，本人基本上所有的代码都在这里写（我没装其他单个语言适配的集成编辑器，更多的都是自己想办法适配在 vscode 里，应用社区十分活跃，能找到很多可替代的解决方案，目前的个人能力下，vscode足以应付）。让我喜欢的还有一点就是其 SSH 连接服务器并编辑文件、集成终端很好用。
>
> - 写文章、心得、文档、其他记事等内容，使用 Typora；
> - 只要是和代码有关的，以及服务器运维，都使用 vscode；
> - 打开一些小的配置文件例如 `.txt`、`.file` 等，都使用 Notepad3，之所以不用 vscode，是因为其就算是打开轻量的文件都要加载很多插件，启动速度不如 Notepad3

- Windows、Linux
- [Visual Studio Code](https://code.visualstudio.com/)

## PicGo

> 配套 Typora 写文章所用的**开源**软件，其作用就是将 markdown 文档中的图片上传到云端对象存储服务器，例如阿里云的 OSS 对象存储。

- Windows
- [Molunerfinn/PicGo](https://github.com/Molunerfinn/PicGo.git)

## FileZilla

> **免费**的 FTP 传输管理工具，在 linux 里使用 apt、yum 等包管理器直接部署，然后在 Windows 使用软件就能很好地连接到 Linux 上，传输带暂停、移动等管理功能。

- Windows、Linux
- [filezilla](https://www.filezilla.cn/)

## XnView

> 用以替代 Windows 下原本的图片查看工具，基础版**免费**且够用

- Windows
- [XnView](https://www.xnview.com/)

## BandiZip

> 替代 Windows 下的解压缩工具，支持多种格式，软件应用过程无捆绑（反正就是没一些软件那么流氓），新版本免费款会弹窗赞助，但是**免费**款功能都够用。如果不想要受干扰，可以去下载旧版本。

- Windows
- [Bandizip](https://www.bandisoft.com/bandizip/)

## SumatraPDF

> **开源**，替代 Windows 下其他所有的 pdf 查看工具，基本功能都够用，我确实是没想到其他的 pdf 查看工具是哪来勇气将基础功能收费的。

- Windows
- [sumatrapdfreader/sumatrapdf](https://github.com/sumatrapdfreader/sumatrapdf.git)
