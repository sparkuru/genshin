## 验证边界

本轮验证了软件安装、文件完整性、Vulkan 枚举、无模型提示和路径移动。没有模型，因而**本轮没有验证 Qwen3-ASR/Hy-MT2 实际 GPU 推理、字幕质量或延迟**。新设备放入模型后，需按 INSTALL.md 的 GPU 日志和英语测试步骤验收。

先前完整部署已在这台 RX 9070 XT 上完成双模型测试：CrispASR 使用 Vulkan，翻译 33/33 层 GPU offload；两进程专用显存合计约 4.02 GiB；英语视频经 WASAPI 捕获、原文和简体中文输出、关闭子进程以及另一盘符复制运行均通过。该结果来自先前部署，不能当作此次无模型安装或其他设备的测试结果。
