# 第二步：GPU 配置

# 第八步：性能优化

针对 RX 9070 XT 16GB 优化。

原则：

- ASR 尽量 GPU 加速
- 翻译模型尽量 GPU 加速
- 尽量让模型常驻显存
- 不要每句话重新加载模型
- 不要每段音频重复初始化 Vulkan
- 控制延迟
- 避免 CPU/GPU 来回拷贝造成不必要延迟

目标不是最低显存占用，而是：

低延迟 + 稳定 + 翻译质量。

如果存在：

- GPU layers
- context size
- batch size
- threads
- VAD
- chunk length
- overlap
- translation context

等参数，根据实时字幕场景进行合理配置。

# 遇到问题时的处理原则

不要一遇到 Vulkan 问题就改成 CPU。

排错顺序：

1. AMD 驱动
2. Vulkan Runtime
3. Vulkan 设备枚举
4. CrispASR 是否为 Vulkan build
5. GGML Vulkan backend
6. 相关 DLL
7. 模型兼容性
8. 程序配置

只有确认 Vulkan 当前版本确实无法工作，才临时使用 CPU 做诊断。

不要安装 CUDA。

---

# 编译原则

尽量避免自行编译。

优先顺序：

1. 项目官方 portable / standalone Release
2. 官方预编译 CrispASR Vulkan Windows binary
3. 官方预编译依赖
4. 本地 Python portable 环境
5. 最后才是从源码编译

如果必须编译：

- 编译完成后，把运行所需 exe / DLL 提取进 portable 目录
- 编译工具不要成为最终运行依赖
- 最终运行目录不能依赖 Visual Studio 开发环境
- 尽可能避免要求永久安装 CMake / Ninja / Vulkan SDK
