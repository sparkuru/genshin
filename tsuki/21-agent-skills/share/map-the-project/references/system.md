# System Module

Use this module for a system where interactions, control, flows, and emergent behavior matter more than any single component. It may be technical, organizational, operational, or socio-technical.

## Discover

- Define the system purpose, boundary, environment, owners, users, and affected parties.
- Identify components, interfaces, resources, controls, states, and dependencies.
- Trace material, information, value, or decision flows from trigger to outcome and feedback.
- Look for constraints, bottlenecks, failure modes, incentives, adaptation, and observability.

## Map

Use the relevant dimensions:

- purpose, boundary, environment, and success conditions;
- actors, components, interfaces, and ownership;
- inputs, transformations, outputs, and feedback loops;
- control mechanisms, constraints, and dependencies;
- operating states, failure modes, resilience, and adaptation.

## Assess

Assess whether the system's structure and feedback make its intended outcomes likely under real constraints. Highlight single points of failure, ambiguous ownership, delayed feedback, perverse incentives, or unobserved transitions only when evidence supports them.
