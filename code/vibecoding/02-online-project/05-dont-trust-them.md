
# 反驳我

做重大决策之前，先让 LLM 竭尽全力唱反调；让 LLM 先全盘驳斥你的选择，再输出参考建议。

1. 先禁止支持我，全力反驳，找出遗漏信息、盲目乐观假设、不可逆成本、机会成本、最坏风险、情绪带来的认知偏差；
2. 切换支持视角，列出该决定成立的核心理由；
3. 中立对比关键证据，告诉我哪边占优势、最大未知风险，出现哪些条件结论会反转，不要刻意平衡观点，拒绝强行五五开。
